GitHub

GitHub es una plataforma para desarrolladores que permite crear, almacenar, administrar y compartir código utilizando Git como sistema de control de versiones distribuido. Además, ofrece herramientas como control de acceso, seguimiento de errores, gestión de tareas, integración continua y wikis para cada proyecto.

Desde 2018 pertenece a Microsoft y tiene su sede en San Francisco.

Es ampliamente utilizado para proyectos de software de código abierto y se ha convertido en el mayor servicio de alojamiento de código fuente del mundo. Para 2023 contaba con más de 100 millones de desarrolladores y cientos de millones de repositorios. En 2025 superó los mil millones de repositorios alojados.

Historia

La plataforma comenzó a desarrollarse en 2007 y fue lanzada en 2008 por Tom Preston-Werner, Chris Wanstrath, P. J. Hyett y Scott Chacon. En sus primeros años fue financiada por sus propios fundadores, aunque posteriormente recibió importantes inversiones que impulsaron su crecimiento.

En 2018 Microsoft adquirió GitHub por 7.500 millones de dólares. La compra generó algunas preocupaciones dentro de la comunidad tecnológica, aunque GitHub continuó operando de manera independiente y mantuvo su enfoque en el software de código abierto.

Servicios

Entre sus principales servicios se encuentran los repositorios públicos y privados, GitHub Pages para alojar sitios web, GitHub Actions para automatizar procesos de desarrollo, Gist para compartir fragmentos de código y programas educativos para estudiantes y desarrolladores.

Objetivo

Su objetivo principal es facilitar la colaboración en proyectos de software mediante herramientas para el control de versiones, revisión de cambios, seguimiento de problemas y trabajo en equipo. También incluye funciones sociales como seguidores, comentarios, discusiones y estadísticas sobre la actividad de los proyectos.
